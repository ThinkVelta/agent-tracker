# Agent Tracker

Keep track of your agent sessions in your MacBook's Menu Bar.

## What is this?

Agent Tracker is a lightweight macOS menu bar app that gives you an at-a-glance
view of your running AI agent sessions (Claude Code, etc.) — so you always know
what's running, what's waiting on you, and what's done, without cycling through
terminal windows.

## Planned features

- **Menu bar status** — a glanceable indicator showing how many agent sessions
  are active, idle, or waiting for input.
- **Session list** — a dropdown listing each session with its project, current
  state, and how long it's been running.
- **Notifications** — get pinged when a session finishes or needs your attention.
- **Quick actions** — jump to the terminal/window a session lives in.
